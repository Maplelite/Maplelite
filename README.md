# Maplelite

A v62-style Maple adventure in your browser. **Play: https://maplelite.github.io/Maplelite/**

This repository is only the public game client (version 3.5). The game database, accounts and characters live on the
game server (https://maplelite.maplelite.workers.dev); this page downloads what it needs from there when it starts.

Fan project, not affiliated with Nexon.
